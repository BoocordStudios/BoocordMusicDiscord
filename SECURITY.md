# Security policy

## Supported versions

| Version | Security updates |
| --- | --- |
| 5.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not open a public issue or discussion for a suspected vulnerability, leaked credential, or exploitable configuration.

Use GitHub's private **Report a vulnerability** form in the repository's Security tab:

<https://github.com/BoocordStudios/BoocordMusicDiscord/security/advisories/new>

Include the affected version, impact, reproduction steps, and any suggested mitigation. Remove real bot tokens, database passwords, and unrelated personal data. Maintainers will acknowledge the report, investigate it privately, and coordinate disclosure and a patched release when appropriate.

If a Discord token or database credential was exposed, revoke or rotate it immediately; deleting it from Git history is not sufficient.
